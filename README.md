# 反应优化



- `code/`：锁定的运行环境、配置文件、模型与优化代码、运行日志、入口脚本、评测脚本及复现说明。
- `doc/`：技术方案说明及生成的 PDF 文件。
- `results/`：两个数据集共 40 个正式 `.pt` 优化轨迹、逐随机种子指标、带 95% 置信区间的汇总指标、轨迹校验记录及结果分析报告。

最终方法为 `optimized_gp_interaction_gp_warmstart_logei`。该方法组合结构化 ANOVA 高斯过程与低秩交互代理模型，第一轮使用高斯过程后验均值热启动，第 2 至 40 轮使用稳定的对数期望改进采集函数。

通俗地说，模型不会把整条反应条件视为一个不可拆分的编号，而是分别判断“底物是否相似、配体是否相似、碱是否相似”等，再额外判断“底物和配体是否同时相似”。因此，即使从未测试过某个完整组合，模型仍能从共享部分组分的历史实验中获得信息。详细解释和公式见 `doc/method_description.pdf` 第 2 至 4 节。

每个数据集均使用主办方规定的 20 个随机种子，每次独立运行推荐 40 个不重复候选。所有轨迹均已完成索引范围、运行内去重、候选条件一致性、best-so-far 单调性、指标重算和 PyTorch 回读校验。
