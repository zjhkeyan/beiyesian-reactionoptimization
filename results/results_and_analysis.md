# 实验结果与分析报告

## 1. 最终提交配置

两个公开数据集均采用 `optimized_gp_interaction_gp_warmstart_logei`。该方法组合结构化 ANOVA 高斯过程和低秩交互代理模型：第一轮按高斯过程后验均值推荐，第 2 至 40 轮使用稳定的对数期望改进采集函数，并根据查询前预测的顺序评分更新模型权重。

其中“反应角色分解的结构化核”是指：分别计算底物、配体、碱、添加剂或溶剂的相似度，将它们作为可独立复用的主效应；再将少数关键角色对的相似度相乘，表达“配体效果取决于底物”“碱效果取决于溶剂”等组合规律。这样可以在初始实验很少时借用部分相同条件的历史信息，同时避免把完全不同的反应组合误判为高度相似。完整公式和实例见 `doc/method_description.pdf` 第 3 节。

每个数据集使用主办方固定的 20 个随机种子：100、200、……、2000。每次独立运行进行 40 轮单点推荐，因此每个数据集包含 800 个顺序查询记录，两个数据集合计 1600 条。

## 3. 指标定义

- `initial_round_found_best`：第一轮推荐并获得反馈后的最高观测产率，越高越好。
- `best_found`：40 轮完整预算内发现的最高产率，越高越好。
- `round_to_95_global_best`：首次达到数据集全局最优值 95% 的轮数，越低越好。若 40 轮内未达到，汇总时记为 41。
- `AUC_best_so_far`：40 个 best-so-far 数值的算术平均，越高越好。

本次最终方法的 40 次独立运行均在预算内达到 95% 阈值，因此未触发 t95=41 的惩罚。

## 4. 结果分析

### Buchwald_sub4

第一轮推荐在全部 20 个随机种子上稳定获得 74.9705，说明高斯过程后验均值热启动有效利用了合并训练集中五种产物的跨任务信息。所有运行最终均找到 83.2944 的高产率条件，平均 t95 为 26.35 轮。AUC 的种子间标准差为 0.5338，表明后续探索顺序存在一定差异，但整体发现曲线较稳定。

### Suzuki

首轮最优值均值为 88.35，明显高于训练集已有最大值；但其标准差为 7.2405，说明不同随机状态仍会影响初始模型拟合和候选排序。最终 `best_found` 达到 99.8395，平均 t95 仅为 5.5 轮，平均 AUC 为 97.1274，显示该方法在 Suzuki 离散组合空间中具有较强的早期发现能力。

### 综合判断

高斯过程第一轮热启动直接改善首轮指标，低秩交互模型在后续轮次提供组合效应补充，稳定 LogEI 则兼顾预测均值与不确定性。该配置在当前公开基准上优于本项目已完成的随机搜索、单模型、三模型集成、指标感知调度、应变新颖度、知识梯度、任务可靠性收缩及 AlphaSwarm 风格候选组合等方案。

上述比较只说明当前公开离线表格上的实验结果。由于最终配置经过公开基准上的多轮筛选，不能据此推断其在内部隐藏数据或新反应体系上的相同优势。

## 5. 优化轨迹格式

每个 `.pt` 文件为一个字典，顶层字段包括：

- `format_version`：轨迹格式版本；
- `dataset`：数据集名称；
- `seed`：本次独立运行的随机种子；
- `method`：方法名称；
- `budget`：查询轮数预算；
- `metrics`：本次运行的四项核心指标；
- `trajectory`：长度为 40 的有序轨迹列表。

每条轨迹至少包含 `round`、`step`、`candidate_id`、`query_index`、`condition`、`observed_yield`、`actual_yield` 和 `best_so_far`，并保留 `predicted_yield`、`uncertainty`、`acquisition_value`、分量预测、在线模型权重及推荐理由等诊断信息。

读取示例：

```python
import torch

run = torch.load("seed_100.pt", map_location="cpu", weights_only=True)
trajectory = run["trajectory"]
```

## 6. 轨迹校验

`trajectory_validation.csv` 记录每个源 JSON 与正式 `.pt` 文件之间的审计结果。独立校验程序已确认：

- 两个数据集各有且仅有 20 个规定文件；
- 每个文件恰好包含 40 条记录；
- 每次运行的 `query_index` 均有效且不重复；
- `condition` 与 feature-only 候选文件对应行逐字段一致；
- `best_so_far` 与顺序观测重算结果一致；
- 四项指标与轨迹重算结果一致；
- 所有文件均可通过 `torch.load(..., weights_only=True)` 回读。

## 7. 防泄漏说明

候选标签只在推荐被提交后由离线 oracle 返回。候选索引无放回查询，编码器在反馈前冻结，每个随机种子使用独立模型和在线权重状态。测试标签和完整搜索空间标签不得用于训练、特征工程、超参数选择或推荐排序。公开表上的方法比较可能产生公开基准过拟合，因此本报告不将其作为隐藏赛道性能证明。
