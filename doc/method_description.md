# 反应条件优化技术方案

## 1. 一分钟理解最终方法

本任务不是在连续数值空间里调温度或时间，而是在一个有限表格中选择“底物、配体、碱、添加剂、溶剂”的组合。每轮只能做一个实验，获得产率后再决定下一轮做什么。

我们的核心思路是：**比较两条反应条件时，先分别比较每一种反应角色，再考虑少数关键角色是否同时匹配。** 例如，两条实验只更换了碱，它们仍共享相同底物和配体，历史信息应当可以部分复用；如果底物和配体同时变化，模型则应更加谨慎。

最终优化器 `optimized_gp_interaction_gp_warmstart_logei` 包含两个互补模型：

- 结构化高斯过程：负责稳定地判断哪些历史实验与当前候选相似，并给出预测值和不确定性；
- 低秩交互模型：补充学习“某个配体只在某类底物或某种碱下表现好”之类的组合效应。

第一轮直接选择高斯过程认为产率最高的候选，以提高首轮成绩。第 2 至 40 轮使用稳定 LogEI，在“预测产率高”和“仍有探索价值”之间取得平衡。

## 2. 什么是反应角色

“反应角色”不是新增加的化学变量，而是对原始表格列的分组。每个角色在反应中承担不同功能，因此不应把它们混成一个无法解释的长向量。

Suzuki 数据集包含以下角色：

- `Electrophile`：亲电底物；
- `Nucleophile`：含硼亲核试剂；
- `SubstratePair`：由亲电底物和亲核试剂组成的联合标识，仅用于建模，不是新的候选变量；
- `Ligand`：配体；
- `Base`：碱；
- `Solvent`：溶剂。

Buchwald_sub4 数据集包含以下可变角色：

- `Reactant2`：芳基卤代底物；
- `Ligand`：配体；
- `Additive`：添加剂；
- `Base`：碱。

Buchwald 训练表中的 `Product` 用来区分五个相关产物任务，属于任务上下文，不是可优化条件。

每个角色内部使用两类不依赖标签的特征：一是精确类别身份，例如“是否为当前这个配体”；二是保守的名称规则，例如名称中是否包含溴、碘、硼酸、膦、杂芳环、氟代基团等提示。编码器在第一次推荐之前固定，此后不会随着反馈改变坐标。

## 3. 什么是反应角色分解的结构化核

### 3.1 核在这里做什么

高斯过程中的“核”可以理解为一个**历史实验可借鉴程度计算器**。给定两条反应条件 A 和 B，核输出一个相似度：值越大，模型越愿意用 A 的产率帮助预测 B；值越小，说明 A 对 B 的参考价值有限。

普通做法会把所有角色拼成一个长向量，再计算一次整体距离。这样容易出现两个问题：

- 只换了一个组分，也可能让整体距离突然变大，浪费其他相同角色的信息；
- 模型难以说明相似性来自底物、配体还是碱，也难以表达“底物与配体必须同时合适”。

结构化核先按角色分别计算相似度，再组合这些相似度，因此更适合小样本的离散反应空间。

### 3.2 第一步：分别计算每个角色的相似度

对每个角色 r，模型都计算一个 RBF 相似度：

```text
k_r(A, B) = exp[- d_r(A, B)^2 / (2 * ell_r^2)]
```

其中 `d_r` 只比较角色 r 的冻结特征，`ell_r` 是由已有观测拟合的尺度参数。

- `k_r` 接近 1：两条反应在该角色上相同或很相似；
- `k_r` 接近 0：两条反应在该角色上差异较大；
- 每个角色有自己的尺度，因此模型可以学习“配体差异比溶剂差异更重要”或相反。

### 3.3 第二步：相加得到角色主效应

模型先把各角色相似度加权相加：

```text
主效应 = w_底物 * k_底物 + w_配体 * k_配体 + w_碱 * k_碱 + ...
```

这一步意味着只要两条实验在部分角色上相似，就可以部分共享信息。例如候选 B 与历史实验 A 使用相同底物、配体和溶剂，只更换了碱，那么 A 仍然是预测 B 的重要依据，而不会因为一个角色变化就被完全丢弃。

### 3.4 第三步：相乘表示关键角色交互

有些效应不能仅靠相加表达。例如某个配体是否有效，可能取决于所用底物。对此模型加入角色对的乘积项：

```text
底物-配体交互 = k_底物(A, B) * k_配体(A, B)
```

只有当两条实验在底物和配体上都相似时，这一项才会较大。这正对应“该配体在这类底物上的经验可以迁移”；如果底物或配体有一个明显不同，交互项会自动减弱。

最终条件核可概括为：

```text
k条件 = [常数 + 所有角色主效应 + 少数关键角色对交互] / 归一化系数
```

代码中的准确形式为：

```text
k条件(A,B) = [1 + Σ_r w_r k_r(A,B)
                 + s_pair Σ_(a,b) w_ab k_a(A,B)k_b(A,B)] / Z
```

`w_r` 控制各角色的先验重要性，`w_ab` 控制各角色对的重要性，`s_pair` 是由数据拟合的统一交互强度，`Z` 用于保持核的数值尺度稳定。所有权重均保持非负，因此得到合法的高斯过程协方差。

### 3.5 实际使用了哪些交互

模型没有把所有角色两两相乘，而是只保留有反应意义且事先写入配置的组合：

| 数据集 | 结构化核中的角色对 |
| --- | --- |
| Suzuki | 底物对-配体、底物对-碱、碱-溶剂、配体-碱、亲电底物-配体、亲核试剂-碱 |
| Buchwald_sub4 | 芳基卤代底物-配体、底物-添加剂、配体-添加剂、配体-碱、添加剂-碱 |

例如在 Suzuki 中，如果一条历史实验和一个候选使用相近的亲电/亲核底物组合以及相同配体，那么“底物对-配体”项会增强二者联系；如果只相同配体但底物组合完全不同，模型仍可借用配体主效应，但不会过度借用底物-配体组合经验。

### 3.6 Buchwald 如何利用五个产物任务

Buchwald 训练集包含五个产物，每个产物只有少量初始实验。模型在上述条件核之外再乘一个产物任务相似度：同一产物之间联系最强，不同产物之间只按学习到的相关程度共享信息。

直观地说，其他四个产物的数据用于回答“哪些配体、添加剂和碱通常有效”，目标产物自己的七条数据用于校正“这些规律在当前产物上应当相信多少”。其他产物的测试标签从未用于训练或推荐。

## 4. 为什么还需要低秩交互模型

结构化高斯过程用预先选择的角色对表达组合效应，稳定且可解释，但仍可能遗漏更细的离散组合规律。因此加入第二个低秩交互模型作为补充。

该模型先把每个角色压缩成少量无标签潜在维度，再对选定角色对计算外积。例如“底物潜在表示 × 配体潜在表示”形成一组组合特征，随后用带收缩的贝叶斯线性回归预测产率和不确定性。

“低秩”表示模型只保留少量主要变化方向，不为每一种完整条件组合单独设置参数。这样既能表达组合效应，又避免在 29 条 Suzuki 初始数据或每个产物 7 条 Buchwald 初始数据上产生严重过拟合。

两个模型并非简单平均。系统根据每轮查询前已经保存的预测误差更新下一轮权重：近期预测更可靠的模型获得更高权重，但每个模型保留最低权重，避免一次偶然误差将某个模型永久淘汰。

## 5. 每轮如何选择实验

1. 读取初始带标签训练集和无标签候选池，构建并冻结特征。
2. 拟合结构化高斯过程和低秩交互模型。
3. 第一轮选择高斯过程后验均值最高的候选，优先保证首轮发现质量。
4. 候选提交后，离线 oracle 只返回该候选的产率。
5. 将新观测加入训练集，更新两个模型及其在线权重。
6. 第 2 至 40 轮计算稳定 LogEI。预测值高且存在合理不确定性的候选得分更高。
7. 从未查询候选中选择得分最高者，并记录完整诊断信息。

LogEI 是期望改进 EI 的数值稳定形式。它没有改变“寻找可能超过当前最好结果的点”这一含义，只是避免普通 EI 在极小概率区域下溢为完全相同的零，导致候选无法排序。

## 6. 数据集特征处理

Suzuki 的可优化输入为亲电试剂、亲核试剂、配体、碱和溶剂。官方修正后的偶联产物 `6-(5-methyl-1-(tetrahydro-2H-pyran-2-yl)-1H-indazol-4-yl)quinoline` 作为固定 `ProductContext` 保存在元数据中，不是候选变量。固定催化剂也不参与候选选择。

Buchwald_sub4 使用 `Product` 区分五个训练任务。`palladium(2+) diacetate` 明确记录为固定催化剂；固定反应物 1、溶剂和催化剂均不是可优化变量。

模型不会仅凭名称编造 canonical SMILES。依赖产物标准结构的反应分子差分特征保持关闭。实验中评估过经来源审计的 Morgan 分子指纹，但未提升整体指标，因此没有进入最终配置。

## 7. 实验筛选过程

实验先比较随机搜索、单高斯过程、单交互模型、树模型、双/三模型集成、贪心后验均值和不同采集策略，再研究迁移学习、多任务学习、分量 ARD、知识梯度、任务可靠性收缩、图扩散、分子指纹和群体搜索等方向。

部分复杂方法改善了某一指标或某类训练代理任务，但同时降低首轮表现、最终最优值、AUC 或稳定性。最终配置的选择原则不是“模型越复杂越好”，而是四项官方指标和多随机种子稳定性整体更强。

## 9. 方法的主要优点

- 可解释：能够指出信息来自哪个反应角色以及哪个角色组合。
- 适合小样本：相同底物、配体或碱的经验可以分别复用，不需要见过完整组合。
- 能表达组合效应：乘积项和低秩交互模型都可描述“某组分是否有效取决于另一组分”。
- 有不确定性：高斯过程和贝叶斯交互模型都输出预测不确定性，可用于探索。
- 严格顺序更新：当前轮反馈只能影响未来轮次，不能反向影响当前推荐。

## 10. 局限性和防泄漏声明

- 交互角色对需要预先指定，未列出的高阶交互只能由第二个模型间接近似。
- 当前表示主要依赖类别身份和保守名称规则，不能替代经过审核的分子结构和反应机理描述符。
- 离线表格 oracle 不能完全反映真实实验噪声、失败机制和批次漂移。
- 最终配置经过公开基准筛选，公开结果不能直接视为隐藏数据或其他反应体系上的 SOTA 证明。
- 候选标签只在候选被提交后返回；候选无放回查询；编码器在优化开始前冻结。
- 每个随机种子使用独立模型、轨迹和在线权重状态，不预先读取测试标签或完整搜索空间标签。
